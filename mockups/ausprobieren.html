Wendet den Callback auf die Elemente der übergebenen Arrays an.

Beschreibung

array_map(?callable $callback, array $array, array ...$arrays): array

array_map() gibt ein Array zurück, das die Ergebnisse enthält, wenn der Callback auf den jeweiligen Wert von array (und von arrays, falls weitere Arrays übergeben werden) als Argument angewendet wird. Die Zahl der Parameter, die der Callback annimmt, sollte der Zahl der an array_map() übergebenen Arrays entsprechen.

Parameter

$callback?callable
Ein Callable, das für jedes Element jedes Arrays ausgeführt wird. Mit null als Callback entsteht eine Zip-Operation über mehrere Arrays (siehe Beispiel 4).
$arrayarray
Ein Array, das durch die Callback-Funktion läuft.
...$arraysarray
Weitere Arrays als variable Liste, die ebenfalls durch die Callback-Funktion laufen.

Rückgabewerte

Gibt ein Array mit den Ergebnissen des Callbacks zurück. Die Schlüssel von array bleiben genau dann erhalten, wenn genau ein Array übergeben wird; bei mehreren Arrays hat das Ergebnis fortlaufende ganzzahlige Schlüssel.

Beispiele

Beispiel 1: array_map()
<?php
function cube($n)
{
    return ($n * $n * $n);
}

$a = [1, 2, 3, 4, 5];
$b = array_map('cube', $a);
print_r($b);
?>

Beispiel 2: array_map() mit einer Lambda-Funktion
<?php
$func = function(int $value): int {
    return $value * 2;
};

print_r(array_map($func, range(1, 5)));

// Or as of PHP 7.4.0:

print_r(array_map(fn($value): int => $value * 2, range(1, 5)));
?>
